拆开选择与执行信用，9B 成功率 40.8%→53.2%

Separating selection credit from execution reward lifts a 9B agent from 40.8% to 53.2% success.

智能体不是不会做事，而是不会选技能：同一批候选里，正确技能的名字只占很少 token，却要靠整条 trajectory 的 outcome 回传来学，结果信号被稀释，还常常反向。作者把这叫 selector credit starvation，并指出它随 horizon 变长而恶化。

关键动作是把选择和执行拆开记账。SkillGate 把 read call 从 task loss 里整段删掉，让 outcome advantage 只更新 execution tokens；另起 selector channel，只把 group-centred 的 action-local advantage 放到 skill identity tokens 上，且只有单次 read 到 oracle 才给正信号。损失写成 $\mathcal{L}(\theta)=\sum_t w_t^{\mathrm{task}}\ell^{\mathrm{clip}}(r_t,A^{\mathrm{task}})+\lambda\sum_t w_t^{\mathrm{sel}}\ell^{\mathrm{clip}}(r_t,A^{\mathrm{sel}})+\beta\mathcal{L}_{\mathrm{KL}}$，两路 token mass 在每个 batch 里重标到同一总量。

在五个 agentic benchmarks、$K=16$ 的 mixed slate 上，9B policy 的 trial success 从 $40.8\%$ 提到 $53.2\%$，高于 outcome-only RL 的 $47.0\%$；oracle exposure 到 $83.9\%$，misleading exposure 降到 $21.8\%$。对 12,800 条训练轨迹的审计还显示，skill 名称 token 只拿到中位 $0.14\%$ 的 loss weight，随长度约稀释 $7\times$，而正确读取 oracle 的 choice 价值有 $+11.2$ pp success。

它说明 skill selection 不是靠更大的 model 就会冒出来的能力，而是要单独训练的 mid-episode decision。代价也清楚：它依赖已知 oracle 的训练任务，且这种 action-local 设计不能奖励 abstention；作者也只做了单次 run，稳健性主要靠 bootstrap。

Agents usually fail here not because they cannot execute a skill, but because they cannot choose one: the chosen skill name is only a few tokens long, yet outcome-only RL spreads one trajectory-level advantage over the whole rollout. The result is selector credit starvation, which gets worse as horizons grow.

SkillGate’s move is to separate selection from execution in the loss. It removes every read call from the task mask, so terminal reward updates only execution tokens, and adds a selector channel that puts an action-local, group-centred advantage only on the skill-identity tokens, with a positive signal only for a single read of the oracle. The objective is $\mathcal{L}(\theta)=\sum_t w_t^{\mathrm{task}}\ell^{\mathrm{clip}}(r_t,A^{\mathrm{task}})+\lambda\sum_t w_t^{\mathrm{sel}}\ell^{\mathrm{clip}}(r_t,A^{\mathrm{sel}})+\beta\mathcal{L}_{\mathrm{KL}}$, and both token supports are rescaled to the same batch mass.

On five agentic benchmarks under a $K=16$ mixed slate, the 9B policy rises from $40.8\%$ to $53.2\%$ trial success, ahead of outcome-only RL at $47.0\%$. Oracle exposure reaches $83.9\%$ and misleading exposure falls to $21.8\%$. An audit of 12,800 training trajectories also shows the selection tokens get a median $0.14\%$ of loss weight, dilute by about $7\times$ with length, and the correct oracle read is worth $+11.2$ pp.

The practical message is that skill selection is a separate mid-episode decision, not something scale will automatically fix. The boundaries are real: training assumes known oracle skills, the action-local scheme cannot reward abstention, and the paper reports only one run per configuration, with uncertainty from bootstrap rather than seeds.

按时间意图重排记忆索引，准确率提 $14.2\%$

Temporal-intent retrieval over context-augmented indices lifts agentic QA accuracy by $14.2\%$.

现有 long-horizon egocentric memory 常把短 caption 和 speech transcript 直接做索引，结果是 coreference、ellipsis 以及人物/物体/地点上下文被截断；检索阶段再靠 semantic similarity 排序，也抓不住 last、usually 这类 temporal intent。问题不在于记忆结构不够复杂，而在于索引本身先丢了信息。

EgoCITE 的关键动作是先补全再检索。EgoScheme 用局部 context 把碎片化 caption/transcript 变成 self-contained atomic memory indices；EgoIndex 再把它们分成 Action、Activity、Utterance、Conversation 四个 view。检索时，EgoRetrv 让 drafting agent 发出 semantic/view/time query，用 $S_i=\mathrm{sim}(f(Q_s),f(m_i))$ 和时间衰减 $R_i$ 合成 $S_iR_i$，默认 $\lambda=0.99$；sampling agent 再按 temporal intent 选证据。

在 EgoLifeQA、EgoMem、EgoR1-Bench 上，它比 agentic memory baselines 的准确率至少高 $14.2\%$、$4.4\%$、$9.0\%$；对 long-context LLM agents，也分别高 $3.6$–$8.9$、$0.9$–$4.1$、$2.6$–$4.7$ 个百分点，同时只用 $23\times$ 更少 input tokens。检索上，EgoCITE-GPT 的 hit rate 达到 $49.6\%$、$89.6\%$、$62.7\%$，比最佳 baseline 最高高出 $15.1$、$17.0$、$22.7$ 个百分点；$5$ 轮 retrieval 还能把 EgoLifeQA 的 hit rate 从 $36.5\%$ 提到 $49.6\%$。

这说明收益主要来自两点：索引阶段把局部 context 写进 memory，检索阶段把时间意图显式化。代价是评测仍以多项选择 QA 和 ground-truth timestamps 为主，而且系统仍依赖较干净的 caption/transcript；作者也把 noisy perception、open-world identity resolution 和更长记录列为未解决问题。

Current long-horizon egocentric memory systems often index short captions and speech transcripts as-is. That loses coreference, ellipsis, and local references to people, objects, and places; at retrieval time, a pure semantic ranking also cannot tell whether the user asked for the last, first, or usual occurrence. The failure is structural: once the index has dropped context, a stronger retriever cannot recover it.

EgoCITE attacks that by separating construction from retrieval. EgoScheme uses local multimodal context to turn fragmentary captions and transcripts into self-contained atomic memory indices, and EgoIndex stores them in four views: Action, Activity, Utterance, and Conversation. EgoRetrv then has a drafting agent issue semantic, view, and time queries, scores candidates with $S_i=\mathrm{sim}(f(Q_s),f(m_i))$ times a temporal relevance term $R_i$, with exponential decay controlled by $\lambda=0.99$, and hands the pool to a sampling agent that curates evidence according to temporal intent.

On EgoLifeQA, EgoMem, and EgoR1-Bench, EgoCITE improves accuracy over agentic memory baselines by at least $14.2\%$, $4.4\%$, and $9.0\%$, respectively. Against long-context LLM agents, it is ahead by $3.6$–$8.9$, $0.9$–$4.1$, and $2.6$–$4.7$ points on the three benchmarks, while using $23\times$ fewer input tokens. Its retrieval hit rate reaches $49.6\%$, $89.6\%$, and $62.7\%$, up to $15.1$, $17.0$, and $22.7$ points above the best baseline. Five-round retrieval raises EgoLifeQA hit rate from $36.5\%$ to $49.6\%$.

The takeaway is straightforward: the win comes from making memory entries self-contained before search, then modeling temporal intent explicitly during search. The catch is that the evaluation is still multiple-choice QA with ground-truth timestamps, and the system still depends on relatively clean captions and transcripts; the authors flag noisier perception, open-world identity resolution, and longer recordings as open problems.

Current UQ for LLM agents leans on local signals such as token probabilities, predictive entropy, or per-step confidence. That misses how errors accumulate over long execution traces, so failures whose cause appears several reasoning or tool-use steps earlier can look confident at the end.

RUPA’s move is to treat an execution history as a directed trajectory graph. Reasoning states, tool interactions, and environment feedback become nodes linked by temporal and semantic dependency edges; uncertainty is then propagated over that graph, and the propagated signal is fused with trajectory-level behavioral features and goal-alignment information to score confidence for the whole trajectory.

The paper evaluates this on $\tau$-2, Terminal-Bench-2, and GAIA with 6 open-source LLMs across multiple model families. The abstract does not report exact scores, but it claims RUPA consistently beats existing UQ methods, with better uncertainty estimates, earlier failure detection, and stronger uncertainty-guided execution.

The main gain is conceptual rather than cosmetic: it turns agent UQ from a stepwise confidence readout into relational risk tracking over the full trace. The limitation is obvious from the abstract-only view: no concrete numbers, no ablations, and no evidence yet on how far the graph propagation scales when trajectories get longer or tool chains get messier.

多轮 tool-calling 的蒸馏卡在一件事：把整条 trajectory 当成唯一正确答案。对顺序无关的子目标，这会把合法探索也一起压掉；而 GRPO 这类 RL 又把奖励摊到所有中间步，credit 乱分，最后学到的是更长的轨迹，不是更稳的策略。

DART-SD 的动作是把执行过程改写成 ISTG。teacher rollouts 先被压成共享的 interaction-state space，把信息获得和无用探索分成 main/aux nodes；student rollout 再投影到成功可达区 $\mathcal{R}_{x}^{+}$，把第一次从可投影到不可投影的点定义为 CTB。训练只在 CTB 后的 recovery assistant tokens 上算 masked loss，前缀、工具观察和 final answer 都不回传梯度。

实验用 FTRL 训练，在 2,215 个任务上做 5 轮 CTB-guided localized SFT，主对照用 no-thinking config，评测 FTRL、BFCL、ToolHop、$\tau$-bench 和 RoTBench。Qwen3-8B 的五项平均从 40.33 最强基线涨到 45.58，Qwen3-4B 从 37.62 涨到 39.17。成功轨迹的平均 tool calls 从 4.23 降到 3.55，而 Solve-F1 从 40.37 升到 45.66；在 thinking 设置下，FTRL/BFCL/ToolHop 也都是最优。

这说明收益主要来自“只修复断点、保住前缀”，而不是把整条轨迹硬拷贝得更像。弱点也很清楚：它依赖 teacher rollouts 和成功可达投影，teacher 覆盖不够时，CTB 和 recovery anchor 就会变窄；而主证据仍局限在工具调用型基准，离更开放的 agent 场景还有距离。

Multi-turn tool-calling distillation keeps failing because it treats one full trajectory as the only target. For tasks with order-independent subgoals, that suppresses valid exploration. Standard RL has a different failure mode: reward is spread across intermediate calls, so credit gets misassigned and the model learns longer traces, not better control.

DART-SD changes the unit of supervision. It turns teacher rollouts into an Interaction-State Transition Graph, separating information acquisition from useless exploration with main and auxiliary nodes. A failed student rollout is projected into the success-reachable region $\mathcal{R}_{x}^{+}$, and the first transition from projectable to non-projectable is the Critical Topological Breakpoint, or CTB. Training then masks loss to the assistant recovery steps after the CTB, leaving the valid prefix, tool observations, and final answer untouched by gradient updates.

The paper trains on FTRL, with 5 rounds of CTB-guided localized SFT over 2,215 tasks, and evaluates on FTRL, BFCL, ToolHop, $\tau$-bench, and RoTBench. The main comparison uses a no-thinking config. On Qwen3-8B, the five-benchmark average rises from the best baseline’s 40.33 to 45.58; on Qwen3-4B, it rises from 37.62 to 39.17. Successful traces also get shorter: average tool calls drop from 4.23 to 3.55 while Solve-F1 climbs from 40.37 to 45.66. Under the thinking setting, DART-SD is also best on FTRL, BFCL, and ToolHop.

The main message is that the gain comes from correcting the breakpoint, not overwriting the whole prefix. The catch is that the method depends on teacher rollouts and a success-reachable projection, so weak teacher coverage will narrow the CTB/recovery space. And although the cross-benchmark results are solid, the evidence still sits inside tool-use benchmarks rather than open-ended agent interaction.

多轮 agentic RL 一旦把回合数拉长，训练常常先稳后崩：轨迹和训练上下文不一致，终局稀疏奖励又压坏了回合级 credit assignment，短长轨迹还会因为不同 policy 版本而异步漂移。现有做法多是在扁平轨迹上优化，三个问题一起冒出来。

关键动作是把多轮 rollout 组织成稀疏 reverse tree，并按时间逆序做 turn-level policy update。这样每个决策都对齐其后续 continuation，既能做因果一致的回合级归因，也能通过 on-policy continuation 抑制异步漂移。作者把这套形式化称为 RTPO。

摘要给出的实验结果只有总体结论：在多轮 agentic RL benchmarks 上，RTPO 相比 trajectory-level baselines 提升 $21.50\%$，相比 turn-level baselines 提升 $10.76\%$。摘要还声称理论上它能消除 context mismatch 和 asynchronous drift，减少 credit bias，并收敛到 recursive optimality，但没有给出具体任务名和各项指标。

这篇工作的价值在于，它把“多轮训练不稳”拆成了可对症处理的三个结构性来源，而不是继续靠更大的 batch 或更长的 prompt 硬撑。不过证据目前只见摘要，且没有看到 benchmark、reward 设定和消融；这些结论是否能跨任务保持，还不能从这里确认。

Multi-turn agentic RL often collapses as the rollout gets longer: the training context drifts from the sampled trajectory, sparse terminal rewards make turn-level credit assignment weak, and short and long trajectories can be updated under different policy versions. Those three failure modes are tied together by flattened trajectory optimization, so the instability is structural rather than just a tuning problem.

The core move is to represent multi-turn rollouts as sparse reverse trees and update the policy in temporal reverse order. Each turn is aligned with its downstream continuation, which makes credit assignment causally consistent and lets on-policy continuation suppress asynchronous drift. The paper calls this Reverse-Turn Policy Optimization, or RTPO.

The abstract reports only aggregate gains: on multi-turn agentic RL benchmarks, RTPO improves over trajectory-level baselines by $21.50\%$ and over turn-level baselines by $10.76\%$. It also claims theoretical guarantees that RTPO removes context mismatch and asynchronous drift, reduces credit bias, and converges to recursive optimality, but the abstract does not name the benchmarks or metrics.

The useful part here is the diagnosis: if multi-turn RL fails because the optimization view is flattened, then the fix has to preserve turn order and downstream dependence. The catch is that we only have the abstract, so the empirical scope, reward design, and ablations are unknown. I would treat the theory as plausible but still untested from this text alone.

MDTIM 的关键动作是把 MASK token 设成与有效观测正交的结构位置，再用 masked diffusion 训练直接预测原始值。为了让离散 masked diffusion 适配连续、且带顺序的时间序列，作者加入 Stochastic Discretization，把连续值映射成保留 ordinal 关系的 token。

Current imputation methods often blur missing and observed values in the same representation, so the model never learns an explicit structural distinction. Continuous diffusion methods also tend to predict injected noise rather than the signal we actually need to recover.

MDTIM makes the main move by treating MASK as structurally orthogonal to valid observations and training a masked diffusion model to predict the original values directly. To bridge discrete masking with continuous, ordinal time-series values, it adds Stochastic Discretization, which maps continuous inputs to ordinal-aware tokens while trying to preserve their dynamics.

The abstract only supports a qualitative claim: across diverse benchmarks and missingness settings, MDTIM is said to outperform deterministic and generative baselines and to be more robust and scalable. No dataset names, metrics, or numeric gains are given in the abstract.

The idea is well aligned with imputation: separate what is missing from what is observed, and train on the target you actually care about. But with only the abstract, it is still unclear how much the discretization costs in amplitude fidelity, and whether the gains survive at high missing rates, long horizons, or cross-dataset transfer.
