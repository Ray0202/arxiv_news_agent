单代理 TTS 一旦把推理链拉长，成本迅速上升，context 管理也更容易失手，随后就是发散和 hallucination。作者要补的不是“再想久一点”，而是避免单条链条把自己拖垮。

关键动作是把 TTS 的单位换成 MAS。先用 AgentVerse 和 DeepSeek-R1 生成 500 条多轮协作轨迹 M500，再对 Qwen2.5-32B-Instruct 和 Phi4-14B 做 SFT，让模型学会多角色来回协商的模式；随后加入 CEO agent，依据题目、当前解、反馈和资源，动态决定参与人数、critic 轮数和 token budget。

在 AgentVerse 中，Qwen2.5-32B-MAS w. CEO 在 GPQA、AIME2024、MATH-500、MBPP-S 上分别到 62.1、62.2、95.8、90.5，对应基线 Qwen2.5-32B-Instruct 的 50.2、21.1、84.4、80.2。Phi4-14B 也同步上升；在 MATH-500 和 MBPP-S 上，结果已接近 DeepSeek-R1 的 96.2 和 91.7。

这说明 MAS 可以作为 TTS 的结构升级：先分工，再按难度和回报调度协作深度。但 M500 只有 500 条，作者也承认 CEO 有 centralization 风险；另外，实验主要锁定 AgentVerse 默认编排，跨框架和真实推理成本节省还没被证明。

Single-agent test-time scaling runs into a wall once the trace gets too long: cost climbs, context management gets brittle, and the model starts diverging or hallucinating. The paper is aimed at that failure mode, not at asking one agent to think harder for longer.

The key move is to make multi-agent collaboration the scaling unit. The authors generate 500 high-quality collaborative traces with AgentVerse and DeepSeek-R1, then SFT Qwen2.5-32B-Instruct and Phi4-14B on M500 so the model learns the turn-taking structure of collaborative reasoning. They then put the fine-tuned model back into AgentVerse and add a CEO agent that reads the question, the current solution, feedback, and resource state to decide how many agents to involve, how many critic rounds to run, and how large each agent’s token budget should be.

The main table is the one to read. With CEO, Qwen2.5-32B-MAS reaches 62.1 on GPQA, 62.2 on AIME2024, 95.8 on MATH-500, and 90.5 on MBPP-S, versus 50.2, 21.1, 84.4, and 80.2 for Qwen2.5-32B-Instruct. Phi4-14B follows the same pattern. The paper also reports near-parity with DeepSeek-R1 on MATH-500 (95.8 vs 96.2) and MBPP-S (90.5 vs 91.7).

The claim is plausible: split the reasoning load, then learn how to coordinate it. The catch is that M500 is only 500 traces, and the paper itself notes a centralization risk if the CEO gives a bad early directive. The evaluation is also tied to AgentVerse defaults, so transfer to other MAS setups, and the actual latency savings, are still unproven.

第三方 skill 不是只在安装时危险：它能在调用、执行和工具输出里继续变形，单点过滤也记不住前面已经拒掉过什么。现有防护多半只守一个边界，或把每次调用当成孤立事件，挡一次不等于挡一类绕过。

ClawSentry 的动作是把同一套 policy 放到 AHP 之上：先用 FSPR 做包级只读审计，再把运行时事件规整成 effect envelope，按 $B_t=w_{123}\max(D_1,D_2,D_3)+w_4D_4+w_5D_5$ 和 $S_t=B_t(1+\lambda D_6/3)$ 逐级路由到 L1/L2/L3。session 级 anti-bypass 记住已拒绝效果，把改写参数、换工具和分轮重试都当成同一类 follow-up。

在 SkillInject 上，Codex/GPT-5.4 的 contextual ASR 从 39.55% 降到 2.61%，TSR 只从 83.78% 到 83.05%；在 SkillsSafety 的五个 Work Agent 上，ASR 从 33.5–49.7% 压到 9.09–15.03%，clean skills 的 aggregate TSR 仍是 98.7%。FSPR 在 101 个 package 上还能把 48 个 toxic 包全抓住，另一个后端也识别了 43/48。

这说明边界最好放在 skill 进入上下文之前，而不是事后修补调用结果；代价是 6.7 个百分点的硬性 overblocking。它对 LLM agent 工具调用安全很直接，但 post-action 只能报告证据，不能撤回已返回的 tool result，且未测自适应攻击或 browser/GUI 场景。

Third-party skills are not only dangerous at install time. They can reshape an autonomous agent at invocation, during execution, and even through tool output, while per-call defenses forget that an effect was already denied. That leaves two holes: one boundary is covered, and the same objective re-enters through another surface or another turn.

ClawSentry closes those holes by putting one policy gateway behind AHP. It first runs FSPR, a read-only package audit before first use. Runtime events are then normalized into an effect envelope and routed through L1, L2, and L3 using $B_t=w_{123}\max(D_1,D_2,D_3)+w_4D_4+w_5D_5$ and $S_t=B_t(1+\lambda D_6/3)$. A session-scoped anti-bypass memory ties renamed commands, tool switches, and split-up retries back to the same denied effect, so the gateway reasons over effect identity instead of surface form.

The numbers are decent and fairly tight. On SkillInject, Codex/GPT-5.4 contextual ASR falls from 39.55% to 2.61%, while contextual TSR slips only from 83.78% to 83.05%. Across five Work Agents on SkillsSafety, ASR drops from 33.5–49.7% to 9.09–15.03%, and clean-skill TSR stays at 98.7%. FSPR also distinguishes 48 toxic packages on the 101-package mixed corpus, with another backend finding 43/48, so admission screening is not just a runtime artifact.

The practical lesson is that the boundary belongs before a package can shape the session at all. That is why the paper’s first line of defense is admission review, not post hoc explanation. The cost is real: the poisoned-case diagnostic leaves 6.7 points of overblocking, and post-action analysis only reports evidence rather than retracting a returned tool result. The evaluation also does not cover adaptive attackers or browser/GUI-style agents, so the claim is strongest for the tool-using coding-agent setting the paper actually tests.

多变量时间序列的解释常把特征轴和时间轴拆开算，结果把“哪些变量在某个区间一起变化”这种结构信号切碎了。对模型来说，真正难解释的往往不是单点特征，而是跨变量交互和时间段共现。

关键动作是把解释单元从单个变量或单个时间步，改成 group-segment players：先按跨变量依赖和时间分布漂移切出片段，再把每个片段当成一个 Shapley player 估值。这样做的目标不是更细，而是让解释单位和时间序列里实际形成的联合模式对齐。

Existing SHAP variants for multivariate time series tend to split time and feature axes apart. That fractures the very signals people want explained: interactions among variables that emerge over specific intervals, not at isolated timestamps.

The core move is to define Shapley players as group-segment units. GS-SHAP first forms segments using cross-variable dependence and temporal distribution shifts, then assigns each segment a Shapley contribution. The point is alignment: the explanatory unit is meant to match the joint pattern the model actually uses.

The abstract reports evaluations on four real-world settings: human activity recognition, power-system forecasting, medical signal analysis, and financial time series. GS-SHAP is compared with KernelSHAP, TimeSHAP, SequenceSHAP, WindowSHAP, and TSHAP. On deletion-based faithfulness, measured by DeltaAUC, it improves by about $1.7\times$ on average over the time-series SHAP baselines, and under matched perturbation budgets it is about $40\%$ faster on average in wall-clock time.

That makes the paper interesting as an explanation method, not just another attribution variant: it targets temporal multivariate structure directly. But the evidence is still abstract-only. We do not see ablations on the grouping rule, robustness to different segmentations, or whether the reported faithfulness gain survives outside the chosen deletion setup.

The move is to delay-embed the series and use the maximum persistence of $1$-dimensional homology as a scalar cyclicity functional. For the supercritical Hopf case, the paper derives finite-resolution persistence bounds that tie detectability to orbit geometry, sampling quality, and finite-data perturbations, then uses a derivative-based estimator to locate the critical parameter from the sampled functional.

已有分布型 time-series 方法多走 autoregressive 或 regression 路线，得估计 operator、transport map 或密度模型；当每个时点本来就是一个分布时，这种结构偏重，也不像 scalar forecasting 里的 exponential smoothing 那么轻。

关键动作是把 Euclidean averaging 换成 Wasserstein geodesic 上的 displacement interpolation。WES 直接递推 $u_t^ heta=((1- heta)d+ heta T_{u_{t-1}^ heta\to\nu_t})_\#\mu_{t-1}^ heta$，只用一个 $ heta\in(0,1)$ 控制朝最新分布走多远。作者在 $bb{R}$ 上用 quantile 形式实现，并以 $L_T(\theta)=\frac{1}{T}\sum_{t=0}^{T-1}W_2^2(\mu_t^\theta,\nu_{t+1})$ 估参数。

他们还把观测写成随机 pushforward 的 WES process，并在零均值、四阶矩有界等条件下证明 $\theta_T\overset{p}{\to}\theta_*$. 实证上，在 $10$ 个 equity indices 的 $5$-minute return 分布和 $10$ 个 household residual-demand 分布上，WES 都拿到最低 MWPE；$90\%$ MCS 里它是 $10/10$，而 WAR/ATM/DAM/DoDRM 在两组任务里分别只有 $1/10,2/10,1/10,0/10$ 和 $4/10,1/10,1/10,0/10$。

这篇工作的价值是把 distributional forecasting 压缩成一个像 ES 一样可递推、可估计、可解释的 filter。边界也很清楚：理论和实现都依赖 $bb{R}$ 上的 quantile isometry，multivariate 扩展不直接；而且文中没有显式建模 trend、seasonality 或 covariates，所以它更像 one-step 分布预测的轻量基线，而不是通用结构模型。

Most distribution-valued time-series models still lean on autoregression or regression, which means estimating operators, transport maps, or density families. That is a lot of structure when each timestamp is already a full distribution, and it gives you nothing as simple as classical exponential smoothing for adaptive one-step forecasting. This paper targets that gap directly.

The trick is to replace Euclidean averaging with displacement interpolation along a Wasserstein geodesic. WES updates forecast distributions by $\mu_t^\theta=((1-\theta)\operatorname{Id}+\theta T_{\mu_{t-1}^\theta\to\nu_t})_\#\mu_{t-1}^\theta$, so a single $\theta\in(0,1)$ controls how far the forecast moves toward the newest observed distribution. In one dimension, the update becomes a quantile-space recursion and the loss is just $W_2^2(\mu,\nu)=\int_0^1(U-V)^2dq$; $\theta$ is chosen by minimizing the in-sample one-step Wasserstein loss $L_T(\theta)=\frac{1}{T}\sum_{t=0}^{T-1}W_2^2(\mu_t^\theta,\nu_{t+1})$.

They also give a population WES process built from random pushforward maps and prove consistency: under zero-mean, bounded-moment transport innovations, $\theta_T\overset{p}{\to}\theta_*$. Empirically, WES is tested on daily distributions from $10$ equity indices built from $5$-minute returns and $10$ household residual-demand series. It gets the lowest mean Wasserstein prediction error on all $20$ series, and it is in the $90\%$ model confidence set in every case; WAR/ATM/DAM/DoDRM are much less stable, with MCS retention rates of $1/10,2/10,1/10,0/10$ in the equity task and $4/10,1/10,1/10,0/10$ in the household task.

The practical point is that distributional forecasting does not have to start with a heavy autoregressive model. Here, a one-parameter Wasserstein filter already tracks changing volatility shapes and demand dispersion well enough to beat the paper's baselines. The break point is dimensionality: the exact quantile isometry that makes WES simple is specific to $\mathbb{R}$, so multivariate extension is not straightforward. The model also leaves trend, seasonality, and covariates untouched.
