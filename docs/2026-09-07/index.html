现有自我进化的 agent skill 主要靠累积轨迹反复打磨，但冷启动时往往只有一个初始且不完美的 skill，后面就只能靠专家手写或一次性 LLM 生成。前者贵，后者可能语法对了，执行却不稳。

SkillRevise 的关键动作是把 skill revision 做成执行证据驱动的迭代编辑：先从执行痕迹诊断缺陷，再从通用 memory 里检索修复原则，最后做以执行为锚点的修改。每轮都重新执行候选 skill，用实际效果来选出 revision budget 内表现最好的版本。

作者说它在三项主 benchmark、两项领域研究和六个 LLM 上都优于 one-shot baseline。最明确的数字是 SkillsBench 上 base agent success rate 从 $36.05\%$ 提到 $61.63\%$。摘要还声称修订后的 skills 能跨 executor 和任务环境迁移。

这说明它补的是“没有好轨迹可学”时的空档，而不是只优化有充分日志的持续自我改进场景。摘要没有给出各 benchmark 的逐项结果、修复预算大小，也没有说明失败案例，所以跨环境泛化目前更像是方向性证据。

Current self-evolving agent skills depend on accumulated trajectories, but cold start leaves only an initial skill that is often imperfect. At that point, the fallback is either expensive expert authoring or a one-shot LLM draft: the former is costly, and the latter may be syntactically valid but behaviorally weak.

SkillRevise turns skill improvement into execution-grounded iterative editing. It first diagnoses defects from execution evidence, retrieves repair principles from a general memory, and applies edits anchored in execution traces. Each candidate is then re-executed, and the best observed skill within the revision budget is kept.

The abstract claims gains over one-shot baselines on three main benchmarks, two domain-specific studies, and six LLMs. The clearest reported number is on SkillsBench, where base-agent success rate rises from 36.05% to 61.63%. It also claims that revised skills transfer across both executors and task environments.

The paper is addressing the gap when there is not enough trajectory history to support standard self-improvement. What is still unclear from the abstract is how large the revision budget is, how performance breaks down by benchmark, and which failures remain. So the transfer claim is promising, but at this stage it is only supported at abstract level.

KernelGenBench: A Multi-Source and Multi-Chip Benchmark for LLM-based Kernel Generation

跨源跨芯片上，成功不再可迁移

Cross-source and cross-chip performance does not transfer: KernelGenBench shows no kernel generator dominates all operators or hardware.

现有评测把 operator 来源和硬件平台混在一起看，结果很难判断 LLM/agent 生成 Triton kernel 的能力到底卡在源头、芯片，还是执行框架。更麻烦的是，熟悉的基准一旦换到别的来源或别的设备，正确率和性能都可能失真。

关键动作是把评测拆成两个正交视图：KernelGenBench-MS 看 210 个 operator，覆盖 PyTorch ATen、vLLM 和 proprietary cuBLAS；KernelGenBench-MC 则在 6 个硬件平台上评 110 个语义稳定的 operator 子集。这样可以分别读出“跨来源泛化”和“跨芯片迁移”两件事，而不是把它们揉成一个总分。

作者报告评测消耗了超过 $15$ billion tokens。Agentic execution 提高了 correctness，但没有方法在所有来源和平台上都占优：vLLM 最难，cuBLAS 的性能上限最高，AutoKernel 的 accuracy 从 NVIDIA 上的 $87\%$ 掉到 Iluvatar CoreX 上的 $25\%$。代价也很直观：specialized agents 平均每个成功 operator 要 $4.99$ million tokens，CUDA Optimized Skill 上升到 $6.25$ million。

这篇工作的价值不在某个单点 SOTA，而在把 operator source、hardware platform 和 agentic scaffold 拆成独立维度。它说明在熟悉组合里做对，不代表能部署；但因为只有摘要，仍看不到这些结论对不同 operator 类别和具体 Triton 设定是否稳健。

Existing evaluations blur together operator source and hardware, so it is hard to tell whether LLM- or agent-generated Triton kernels fail because of the source, the chip, or the scaffold around the model. That makes a strong score on one benchmark look more portable than it really is.

The move here is to split evaluation into two orthogonal views. KernelGenBench-MS covers 210 operators from PyTorch ATen, production vLLM operators, and proprietary cuBLAS routines. KernelGenBench-MC tests a semantically stable 110-operator subset across 6 hardware platforms. The same Triton target is used throughout, so the benchmark isolates source transfer from chip transfer.

The abstract reports more than $15$ billion tokens consumed in evaluation. Agentic execution improves correctness, but no method wins everywhere: vLLM is the hardest source, cuBLAS sets the highest performance ceiling, and AutoKernel accuracy drops from $87\%$ on NVIDIA to $25\%$ on Iluvatar CoreX. Cost is also high: specialized agents average $4.99$ million tokens per successful operator, rising to $6.25$ million for CUDA Optimized Skill.

The practical message is that operator source, hardware platform, and agentic scaffold are separate dimensions of capability. Success in a familiar source-hardware pair is not a deployment proxy. The limit is simple too: this is an abstract-only readout, so the robustness of the conclusions across operator families, Triton settings, and per-chip details is still opaque.

Agent evaluation is fragmented, not because there are too few benchmarks, but because every benchmark brings its own environment, interaction protocol, and scoring. Covering $m$ benchmarks and $n$ agents often means $\mathcal{O}(mn)$ integrations, so papers usually report only a few popular suites and comparisons get polluted by implementation differences.

Harbor Adapters attack that directly: they map tasks into Harbor's four-part schema — instruction, environment, tests, solution — so each benchmark needs one adapter and each agent one Harbor integration. The stack also supports sandbox backends, GPU interaction, and LLM-as-a-judge verification, cutting integration down to $\mathcal{O}(m+n)$.

The paper runs $8$ models on $54$ benchmarks and $6{,}627$ tasks under $16$ model-harness configurations, with $3$ repeats, $226B$ input/output tokens, and more than $300K$ compute. The main result is that the base model matters more than the harness: ICC is $0.75$, the model fixed-effect range is $0.451$ versus $0.087$ for harnesses, $13$ benchmarks are already near saturation, $12$ benchmarks are enough to put the rest mostly within $\rho\geq0.7$, and $3$ tasks per benchmark recover the system ranking at mean $\rho\approx0.923$. Frontier models use fewer tokens at every difficulty level, but other models are still $2$–$3\times$ cheaper per run.

Harbor-Index compresses the $6{,}627$-task pool into $82$ tasks across $29$ benchmarks via difficulty filtering, AI/human auditing, and an audit-and-fix loop that strips out tasks that look hard but are structurally broken. It is cheap enough to rerun and still hard — no configuration exceeds $30\%$ pass rate, and GPT-5.5 with Codex reaches $28.0\%$ — but it only covers the $54$ integrated benchmarks, and stronger agents may still exploit verifier loopholes. More sharply, many low scores come from verifier or environment design flaws rather than pure difficulty.

Iris: Climbing to the Search Frontier

现有搜索智能体常把训练数据做得太“干净”，闭卷时不会、开卷就会的题也混进来，导致学到的不是检索能力而是答案抄写。更麻烦的是，推理时上下文管理本身就能显著影响分数，却常被和模型能力混在一起看。

这篇工作的关键动作是把网页超链接结构反过来用来造题：先从种子页和外链蒸馏实体图，再写多跳链路，把所有非答案实体改写成描述性指代，尽量切断字符串匹配捷径。只有当参考模型闭卷失败、给足证据后又能解出来的问题才保留；随后把题目变成 trajectories，先做轨迹级和 turn 级过滤再 SFT，再用 live search 做 RL，并把 reward judge 和 observation summarizer 放在训练集群内。作者把这个两阶段交替称为 SFT-RL climbing，每轮 RL 后把最难且最高效的轨迹回灌到下一轮 SFT。

摘要给出的主结果只在开启 inference-time context management 时汇报。Iris-mini 和 Iris-pro 在 BrowseComp、BrowseComp-ZH、DeepSearchQA、HLE 上分别达到 $82.2/84.8/86.9/52.3$ 和 $88.6/85.1/92.9/56.4$，作者称这是各自参数范围内开源搜索智能体的最强总体结果。文中还强调所有评测都固定了 tool set、context limit 和 judge，而且是单个 ReAct agent，没有 sub-agents，也没有 test-time verification。

这项工作的价值不在“又一个搜索 agent”，而在训练数据和评测控制都直指搜索任务的真实瓶颈：闭卷可解性、证据可用性、以及上下文管理。但摘要只给了开启管理后的总分，没给关闭管理时的对照，也没展开消融，所以很难判断提升有多少来自 SFT-RL climbing，本身又有多少来自推理时工程。

Many search agents are trained on data that is too clean: they learn to parrot answers, not to recover evidence, and then look better on paper than they behave when the answer is not already in the prompt. Worse, inference-time context management can move scores a lot, but that effect is often entangled with the model itself.

The main move here is to build questions backwards from web hyperlink structure. The authors distill an entity graph from a seed page and its out-links, write multi-hop chains over that graph, and rewrite every non-answer entity into a descriptive reference so string matching no longer works. They keep only questions a reference model fails closed-book but solves once the supporting evidence is supplied. Those questions become trajectories, which are filtered at the trajectory and turn level before SFT. Then the policy is optimized with RL against live search, with the reward judge and observation summarizer hosted inside the training cluster. They call the alternation SFT-RL climbing, and after each RL round they feed the hardest solved and most efficient rollouts back into the next supervised pass.

The abstract reports results only with inference-time context management enabled. On BrowseComp, BrowseComp-ZH, DeepSearchQA, and HLE, Iris-mini reaches $82.2/84.8/86.9/52.3$, and Iris-pro reaches $88.6/85.1/92.9/56.4$. The paper says these are the strongest overall results among open-source search agents in their parameter ranges. It also says evaluation keeps the tool set, context limit, and judge fixed, and uses a single ReAct agent with no sub-agents and no test-time verification.

The contribution is less about a new search loop than about making the training data and evaluation protocol match the real failure mode of search agents: whether evidence can be found, compressed, and used under context pressure. But the abstract gives only the managed-context scores, not the disabled-context comparison, and it does not expose ablations, so it is hard to tell how much of the gain comes from the climbing recipe versus inference-time engineering.

现有 forget API 只删明文记录，真正被污染的却是 summary、plan 和 KV cache。于是目标信息虽然从存储层消失，模型还是会在后续回答、tool 参数和写回里继续泄漏；更糟的是，常见评测只看字符串命中，正好把这种失败漏掉。

关键动作是把忘记定义成“像从未见过 $z$ 一样”。作者把 runtime 写成确定性转移系统 $R_t=F(R_{t-1},o_t;\theta)$，证明 $\tau-1$ 之前的前缀可直接复用，而 $\tau$ 之后的状态只要没做 token 级归因就只能整段重放；因此先用 provenance 图定位注入点，再把 KV cache 截到 $\tau-1$，最后对净化后的后缀做 selective replay，精确恢复 $R_T^{-z}$，最坏只需 $T-\tau+1$ 次 transition。

实验在 LongMemEval、ToolSandbox、AgentDojo 上跑了九个 baselines 和三类模型。Memory-Delete 与 No-Forget 完全一样，any-leak 仍是 $0.86/1.00/0.97$；Forget-Instruction 在 Leak@probes 上三套都到 $1.00$，Source-Redaction 还会在 $80\%$ 的偏好回合里继续按被撤销偏好行动。Selective-Replay 则在三套上把 any-leak 和 CAD 都压到 $0$，并以 $133$ 个重算 token 对上 Full-Reset 的 $1235$ 个，约少 $9.3\times$。

Current forget APIs delete the record and stop. In stateful agents, that leaves the derived summary, pending plan, tool trace, and KV cache intact, so the revoked fact keeps steering later answers and actions. Worse, the usual checks are string-match audits, which can pass even when behavior is still contaminated.

The trick is to define forgetting as counterfactual equivalence: the post-unlearning agent should behave like a twin that never saw $z$. The runtime is modeled as $R_t=F(R_{t-1},o_t;\theta)$, and the paper proves that the prefix up to $\tau-1$ is reusable for free, while everything from $\tau$ onward is tainted unless you can attribute influence token by token. That yields Provenance-Guided Selective Replay: locate $\tau$ with a provenance graph, crop the KV cache at $\tau-1$, then replay a sanitized suffix to reconstruct $R_T^{-z}$ exactly, with a worst-case cost of $T-\tau+1$ transitions.

On LongMemEval, ToolSandbox, and AgentDojo, across nine baselines and three model families, the failure modes are blunt. Memory-Delete is a no-op: any-leak stays at $0.86/1.00/0.97$, identical to No-Forget. Forget-Instruction hits Leak@probes $=1.00$ on all three suites. Source-Redaction still acts on a revoked preference in $80\%$ of episodes. Selective-Replay matches Full-Reset on any-leak, CAD, and the behavioral extraction test, while using $133$ recomputed tokens versus $1235$ for Full-Reset.

This is a strong result for runtime unlearning, not a general cure-all. The guarantee covers reconstructible execution state, not model parameters or irreversible side effects, and it assumes the post-$\tau$ observations can be replayed from snapshots. The distributional audit is also evidence of non-divergence, not a formal equivalence proof, so the exactness claim is strongest where the system can actually instrument provenance and restore state.

这把“深度越大越好”改成了更精确的图景：误差能在 $M^2$ 之前保持常数级，之后才进入 $M^2/D$ 衰减。代价是下界构造依赖随 $D$ 变化的合成分布；作者还证明，固定分布只能几何收敛，撑不住所有深度的同一个 $M^2/D$ 下界。

Each agent only sees a slice of the features and forwards a single prediction or logit, so the error does not decay in the clean $O(M/\sqrt{D})$ way Kearns, Roth, and Ryu suggested; their cyclic lower bound still left a real gap.

The trick is to turn the path analysis into an induction. Split the chain in half, show the midpoint already has excess error $O(M^2/D)$, then use a block lemma: if an $M$-covered block barely lowers the loss, the block endpoint must already be close to optimal. The lower bound uses a rotating Gaussian construction where neighboring features differ by a small angle $\delta$, so each step can remove only an $O(\rho^2\sin^2\delta)$ fraction of the remaining residual.

The headline results are clean. For regression on $M$-covered paths, the paper improves the upper bound to $O(M^2/D)$. The cyclic example is sharpened to $\Omega(1/\sqrt{p})$, equivalently $\Omega(\sqrt{M/D})$ when $D=pk$. For every $D\ge M^2$, the new construction gives a lower bound of $\frac{1}{1280\pi^2}\frac{M^2}{D}$. The same picture transfers to BCE logit-passing by a Gaussian transfer theorem.

So quadratic depth is the breakpoint: error can stay at constant scale until about $M^2$, and after that the right rate is $M^2/D$. The catch is that the sharp lower bound needs a distribution that depends on $D$; the paper also proves that any fixed finite distribution only gives geometric contraction along covered paths, so it cannot witness the same lower bound at every depth.

现有时间序列生成要么偏时间域，要么偏频域，结果是多尺度结构学不圆：能看见局部纹理，却常丢掉跨尺度关系。作者把问题转到 wavelet 系数上，目标是让 diffusion 直接在分解后的各层里学生成。

关键动作是给每个分解层配专门的 transformer，再用 cross-level attention 和 adaptive gating 在时频尺度间选择性交换信息；同时加上基于 Parseval 定理的层级能量约束，限制扩散过程别把时频性质弄坏。

摘要只给出六个真实数据集上的总体结论：WaveletDiff 在多数指标上优于 FourierDiffusion、Diffusion-TS 和 SigDiffusions，且相对 FourierDiffusion 在 discriminative 和 Context-FID 上约低约 $3\times$。和 MSDformer 相比，结果大多接近，同时参数更少、训练时间更短；但 fMRI 上明显输给 MSDformer，EEG 上则明显更强。

Existing time-series generators tend to live in either the time domain or the frequency domain, and that split makes it hard to reproduce the multiscale structure real data actually has. The result is often local fidelity without the cross-scale dependencies that matter for realistic generation.

WaveletDiff moves diffusion directly onto wavelet coefficients. It assigns a dedicated transformer to each decomposition level, then uses cross-level attention with adaptive gating to let levels exchange information selectively. A Parseval-based energy constraint is added at each level to keep the time-frequency balance from drifting during diffusion.

The abstract reports tests on six real-world datasets from energy, finance, and neuroscience. WaveletDiff beats FourierDiffusion, Diffusion-TS, and SigDiffusions on most metrics, with the smallest margin over FourierDiffusion, while achieving roughly $3\times$ lower discriminative and Context-FID scores. Against MSDformer, performance is mostly comparable, but WaveletDiff uses fewer parameters and less training time on most datasets.

The main takeaway is conditional, not universal: wavelets seem to help when the target distribution preserves multiscale generative structure, but they are not enough to close every gap. The biggest exception is fMRI, where MSDformer wins clearly; EEG goes the other way. Because this is abstract-only, the causal story for why those regimes diverge is suggestive rather than proven, and the paper does not expose the full per-dataset numbers or ablations here.
