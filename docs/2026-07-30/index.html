Living-Harness Is an Interactive-Agent Evolver

把失败写进可复用流程，Pass@1 提 10.07pp

It turns evaluated failures into reusable harness updates, lifting Pass@1 by 10.07 points on $\tau^2$-Bench.

展开精读read the digest

智能体常能在当前 episode 里修正错误，却把同样的执行失误带到下一轮，因为反馈只改了这次轨迹，没改驱动后续交互的 harness。静态 harness 部署后不再变，reflection 和记忆也多半只存一句教训，不存触发条件、缺失动作和流程转移，所以“该转人工”未必会变成下次真的会调工具。

关键动作是让 harness 自己按回合进化。作者把 $H_d^{(n)}$ 拆成固定执行资源 $C_d^{\mathrm{act}}$、固定的 Evolution-SOP $\psi_d$，以及会更新的状态 $S_d^{(n)}=(\mathcal{R}_d^{(n)},G_d^{(n)})$。每轮先检索相关 memory 和 graph 作为上下文，执行后再把 $(\tau_n,y_n)$ 压成 episode abstraction $e_n$，抽取候选修复 $u_n$，分别写入 episodic memory 和 state graph；工具和 base context 始终冻结。

他们在八个交互环境上测了 $\tau^2$-Bench 的 Retail、Airline、Telecom 和 MultiWOZ-2.4 的 Restaurant、Hotel、Train、Attraction、Taxi。Living-Harness 的平均 Pass@1 到 83.09 和 65.50，分别比最强 interactive baseline 的 73.02 和 55.59 高 10.07 和 9.91 个点；在 $\tau^2$-Bench 上，去掉 Evolution-SOP 会把平均分从 83.09 拉到 73.38。Table 3 还显示，冻结后的 harness state 能跨 backbone 检索复用，GLM-5 的 Taxi 可从 0.00 提到 43.08。

这说明它补的是 agent 里的流程记忆，不是再多一次 retry。真正起作用的是把失败编码成可检索的 repair edge 和触发条件，而不是一段泛化总结；但证据仍只来自两套基准、少数 backbone 和 GPT-5.2/GPT-5.1 这组设置，域外可迁移性和对 noisy evaluator 的鲁棒性还没被证明。

LLM agents can recover inside one episode, but the same failure comes back later because feedback edits the trace, not the persistent harness. A static harness freezes tools, memory, and workflow after deployment, while reflection-style memory often stores a lesson without the trigger condition, missing action, or transition needed to prevent recurrence.

Living-Harness makes the harness state itself evolve. The actor runs with fixed execution resources $C_d^{\mathrm{act}}$ and a fixed domain Evolution-SOP $\psi_d$, while the mutable state is $S_d^{(n)}=(\mathcal{R}_d^{(n)},G_d^{(n)})$. After each rollout, $(\tau_n,y_n)$ is compressed into an episode abstraction $e_n$, extracted into candidate repairs $u_n$, and written back to episodic memory and the state graph; tools and base context stay frozen.

They test this on eight interactive environments from $\tau^2$-Bench and MultiWOZ-2.4. Living-Harness reaches 83.09 average Pass@1 on $\tau^2$-Bench and 65.50 on MultiWOZ-2.4, beating the strongest interactive baselines, Reflexion at 73.02 and ReasoningBank at 55.59, by 10.07 and 9.91 points. The ablation is telling: removing the Evolution-SOP drops the $\tau^2$-Bench average to 73.38. Frozen harness state also transfers across backbones; GLM-5 on Taxi goes from 0.00 to 43.08.

The claim is not that the model learns better next-token reasoning, but that the surrounding procedure can accumulate reusable repairs. That is a good fit for agent work, where repeat failures often come from missing workflow state rather than weak answers. The caveat is scope: the evidence comes from two benchmarks, a small set of backbones, and a setup that relies on a domain-specific Evolution-SOP and evaluator signals; broader generality is still unproven.

Metis: Memory Foundation Model

Metis 把记忆压进参数态，NextMem Avg 到 50.82。

Metis internalizes memory as parametric state and reaches 50.82 Avg on NextMem without context.

智能体的记忆大多还挂在外面：RAG、检索拼接、TTT 都把 backbone 维持成无状态预测器，记忆目标和模型本体分开，端到端训练难，推理还要额外检索。Metis 就是要修这个错位。

关键动作是把记忆改成参数态，直接塞进 backbone。它在每层放一个 local memory block 和一个 hyper memory block：前者存压缩后的历史，后者从当前 token 里选高分位置并更新记忆；读出时把 memory attention 和原 attention 按 $\gamma$ 混合。训练时再用 memory reconstruction、remember/forget/update/reflect 和多实体、污染样本，把记忆操作学成模型内生行为。

在 no-context 设定下，Metis-27B 的 MemOps (Gold) Avg 为 24.76，优于 Temp-LoRA-9B 的 13.51；LoCoMo (Gold) Avg 为 26.74，优于 11.72；NextMem Avg 为 50.82，优于 30.97。作者还报告 Metis test set Avg 73.77，对 Temp-LoRA-27B 的 23.86 提升明显。相比只靠 backbone，Metis 能保住跨轮信息。

这篇工作的价值是把记忆从外挂模块变成可优化的内部状态，比较适合 LLM agent 的持续交互。但它自己也承认，固定大小压缩会丢信息，长程任务和语义混叠仍会掉点，所以它更像可行的 native-memory 底座，不是最终答案。

Agents still bolt memory onto the outside. RAG, retrieve-then-concatenate, and TTT keep the backbone as a stateless predictor; the memory objective sits apart from the model, so end-to-end training is awkward and inference pays extra retrieval cost. Metis is aimed at that mismatch.

The move is to make memory a parametric state inside the backbone. Metis adds a local memory block and a hyper memory block: one stores compressed history, the other picks salient tokens and updates the state; readout mixes memory attention with ordinary self-attention. Mid-training then teaches reconstruction, remember/forget/update/reflect behavior, plus regularization for multi-fact interference and memory pollution.

On no-context evaluation, Metis-27B gets 24.76 Avg on MemOps (Gold) versus Temp-LoRA-9B at 13.51, 26.74 Avg on LoCoMo (Gold) versus 11.72, and 50.82 Avg on NextMem versus 30.97. The paper also reports 73.77 Avg on its Metis test set, far above Temp-LoRA-27B at 23.86. In other words, it preserves cross-turn information without replaying the source context.

The strong part is the claim that memory can be trained into the model rather than appended beside it. The catch is the same fixed-size state that makes this efficient: the authors say long-horizon tasks lose information and some latent states blur together, so this is a plausible native-memory substrate, not a finished replacement for external memory.

方法Method

core idea
Metis 用固定大小的 $\mathbf{M}^{(l)}_t$ 和 $\mathbf{S}^{(l)}_t$ 表示每层的 native memory state。写入时，hyper memory block 从当前层 hidden states 里按 $\rho$ 选 token，经过 $\tilde{\mathbf{W}}_K$、$\tilde{\mathbf{W}}_V$ 投影后更新记忆；读出时，用 $\tilde{\mathbf{Q}}^{(l)}_t\mathbf{M}^{(l)}_t$ 做 memory attention，再和原 self-attention 按 $\gamma$ 混合。训练阶段冻结 backbone，只中训 memory 参数，用 reconstruction、operation 和 regularization 三类目标学出 remember/forget/update/reflect。
Metis represents native memory with fixed-size states $\mathbf{M}^{(l)}_t$ and $\mathbf{S}^{(l)}_t$ in each layer. On write, the hyper memory block selects tokens by $\rho$, projects them through $\tilde{\mathbf{W}}_K$ and $\tilde{\mathbf{W}}_V$, and updates memory; on read, $\tilde{\mathbf{Q}}^{(l)}_t\mathbf{M}^{(l)}_t$ forms memory attention that is mixed with ordinary self-attention by $\gamma$. Mid-training freezes the backbone and optimizes memory-only parameters with reconstruction, operation, and regularization losses for remember/forget/update/reflect.
architecture
Qwen3.5-4B/9B/27B; N Transformer blocks; Metis block = local memory block + hyper memory block; fixed-size memory state $\mathbf{M}^{(l)}_t\in\mathbb{R}^{d_k\times d_v}$, $\mathbf{S}^{(l)}_t\in\mathbb{R}^{d_k}$; memory attention + causal attention mixed by $\gamma$; GDU update.
data
Primary: 27 public benchmarks, 357,137 samples, 406.1M tokens. Auxiliary: 609,443 samples.
compute
8xH100 GPUs; BF16; AdamW; lr 2e-4; 14,000 steps (Metis-4B/27B), 8,000 steps (Metis-9B); seed 42.

LLM agent 换到同族新任务时，学到的套路常被直接丢掉。现有 agentic RL 把每个任务当独立 episode，或把技能学习拆成提炼、检索、执行多阶段管线，导致迁移到底来自技能还是别的模块，难以分清。重复试同一题能缓解，但多半只对单例有效。

SkillRise 的关键动作，是让同一 policy 在一串相关任务里轮流做两件事：先用当前 skill document $S_{i-1}$ 解题，再把这次轨迹改写成下一题可用的 $S_i$。训练时，解题只看当前回报，整理只看后续任务的折扣回报，$\gamma=0.6$；再按序列位置和角色做 group-relative advantage，把两种信号拆开。

在 ALFWorld、WebShop、ScienceWorld 上，Qwen3-1.7B/4B 的 SkillRise 取得最强 Pass@1：85.9%、84.4%、54.6%，比最强 baseline GiGPO 高 2.3、7.1、8.5 个百分点。Pass@3 也最好：92.2%、96.1%、61.0%。它还在重复尝试同一任务时超过 LaMer；在 ALFWorld 上把相关序列从 $K=2$ 拉到 $K=6$，Pass@1 从 83.6% 升到 87.5%。

这说明它学到的不是单次反思，而是可跨任务复用的整理策略。代价也清楚：序列构造依赖 task-family metadata，实验只做到 4B backbone 和三个文本、可验证回报环境，开放式多模态场景还没被证明。

LLM agents still forget what they just learned when the next task is nearby but not identical. Standard agentic RL treats each task as an independent episode. Multi-stage skill pipelines go the other way and split extraction, retrieval, and execution, which makes the credit assignment muddy: is the gain from the skill, the memory, or the retriever? Repeated retries on one task help, but often only within that instance.

SkillRise’s move is simple: one policy both solves and curates. It runs through a sequence of related tasks, solves task $x_i$ with the current skill document $S_{i-1}$, then rewrites that document into $S_i$ for the next task. Solving is trained on the current reward; curation is trained on discounted downstream rewards with $\gamma=0.6$. A role-aware group-relative PPO objective keeps the two signals from collapsing into one.

On ALFWorld, WebShop, and ScienceWorld, a Qwen3-1.7B/4B backbone with SkillRise gets the best Pass@1: 85.9%, 84.4%, and 54.6%, beating the strongest baseline, GiGPO, by 2.3, 7.1, and 8.5 points. Pass@3 is also best: 92.2%, 96.1%, and 61.0%, with gains over the best baseline ranging from 0.8 to 5.5 points. It also beats LaMer on repeated attempts, and on ALFWorld its Pass@1 rises from 83.6% at $K=2$ to 87.5% at $K=6$ as the related test sequence gets longer.

The paper’s real claim is not a better retry trick, but a reusable curation policy that turns earlier interactions into later gains. The caveat is that the setup still assumes task-family metadata for sequence construction, and the evidence stops at three text environments and backbones up to 4B. It remains open whether the same scheme works when task relations must be discovered online, or when reward is less cleanly verifiable.

LLM agents are no longer bottlenecked only by tool finding; they are bottlenecked by how many tools to acquire. PINNs still depend on hand-tuned neural representations, loss terms, and optimization schedules, and that trial-and-error breaks down fast under strict PDE constraints. The abstract claims broad experiments across oscillatory, elliptic, dissipative, and nonlinear transport PDE regimes.
