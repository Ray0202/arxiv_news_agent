长跑型 LLM agent 不是不会记，而是会把临时上下文写成永久状态：同一记忆通道里，短期指令和长期偏好竞争，结果就是 temporary overwrite。已有 memory 多在补容量、补 retrieval，却没区分“这条信息要影响多久”，所以一旦写错生命周期，后面再准的检索也救不回行为漂移。

LifeFuse-Mem 的关键动作，是在写入时先把 memory 拆成 plastic 和 stable 两个子空间，再用监督 router 判断 token 属于 permanent 还是 temporary。报告里的实现把 rank 8 切成 4/4，并学一个近似正交基来做坐标旋转；永久 token 才能更强地更新 stable 行。只有在已知 Phase A/Phase B 的诊断评测里，它才会把 Phase A 的 stable 行和 Phase B 的 plastic 行做 protected fusion，临时 query 则直接读 Phase B。

在 1,000-episode Hard Attribution Anti-Overwrite 上，Qwen3-4B 的 acquisition-controlled Ret. 从 57.72% 到 63.71%，Ovr. 从 42.28% 到 36.29%；SmolLM3-3B 分别从 60.27% 到 69.39%、从 39.73% 到 30.61%。端到端 Perm. 只小幅变化，说明收益主要来自“已学到的事实”不被后写入覆盖。

LoCoMo 和 MemoryAgentBench 上，它保持总体竞争力，但有的类别升、有的降，说明 lifecycle boundary 不是万能增益。消融显示 route supervision 最关键，stable rows 和 retention loss 次之，hard candidate loss 更像校准项。更重要的是，作者自己限定：protected-state fusion 只在已知 Phase A/Phase B 的诊断协议里用，不是自动发现生命周期；再加上只测了 Qwen3-4B 和 SmolLM3-3B，泛化到更大模型、别的 rank 和无标签场景还没被证明。

Persistent agents do not just need more memory; they need memory that knows how long a fact should matter. Here the failure is temporary overwrite: a local instruction gets written into the same compact state as a durable preference, so later turns drift even when retrieval is correct. Prior memory systems mostly optimize capacity or retrieval and miss that lifecycle mismatch.

LifeFuse-Mem fixes this by splitting the online memory state into plastic and stable subspaces, then supervising a router to decide whether each write token is permanent or temporary. In the reported setup, rank 8 is split 4/4 and an approximately orthogonal basis is learned for the coordinates. Permanent tokens are allowed to update stable rows more strongly, and only the controlled Phase A/Phase B benchmark uses the protected fusion readout: Phase A stable rows are combined with Phase B plastic rows, while temporary queries read Phase B directly.

On the 1,000-episode Hard Attribution Anti-Overwrite benchmark, Qwen3-4B improves acquisition-controlled Ret. from 57.72% to 63.71% and lowers Ovr. from 42.28% to 36.29%; SmolLM3-3B moves from 60.27% to 69.39% and from 39.73% to 30.61%. End-to-end permanent-query accuracy changes only a little, so the gain is mainly in resisting overwrite once the fact has already been acquired. On LoCoMo and MemoryAgentBench, the adapter stays broadly competitive, but the category gains are mixed.

The paper's real contribution is diagnostic: it makes lifecycle mismatch measurable and then shows that route supervision is the main source of the retention gain. The limitation is built in. Protected-state fusion is only defined when phase boundaries and query lifecycles are known, so the method does not discover lifecycles from raw interaction history. The evidence also stops at two backbones and a rank-8 adapter.

现在的 LLM agent 把经验存进 memory，却常在换环境时检索到错轨迹，旧经验还会被新任务冲掉。只看语义的 trajectory retrieval 解决不了动作空间不匹配；全局抽 skills 又把无关轨迹混在一起，噪声更大。

LifeMem 的关键动作，是先按 workflow 而不是语义给轨迹分簇，再只在簇内蒸馏 skill。新轨迹先做 top-$k$ 检索并关联到候选簇；当 $n>L$ 且 $R<\tau_{mrl}$ 时再细分，推理时同时取回轨迹和 skill，减少跨环境干扰。

他们在 10 个环境、13k+任务上测，并补了 2k+轨迹。GPT-4o-mini、Deepseek-v3.2-exp、Qwen3-32b 的 average overall performance 分别到 44.13、48.02、46.52；对应最好基线是 41.85、46.38、43.29。零样本转移里，FEVER 到 0.49，对 ReAct 的 0.40；$\tau$-bench airline 到 0.38，对 0.32。

这说明把记忆按 workflow 组织，比把所有轨迹丢进一个池里更能同时压住 forgetting 和 negative transfer。作者也承认，大规模工业部署还要靠轻量端侧模型和近似检索；而零样本证据目前只覆盖 FEVER 和 airline。

Memory-heavy agents do not fail because they lack examples; they fail because the wrong examples come back. In heterogeneous environments, raw-trajectory retrieval collides with mismatched action spaces, so the retrieved trace is often not executable. The opposite extreme, global skill abstraction over an unstructured pool, mixes unrelated behaviors and turns memory into noise.

LifeMem's move is to organize memory by workflow first, then distill skills locally inside each cluster. New trajectories are matched against top-$k$ retrieved neighbors; if $n>L$ and $R<\tau_{mrl}$, the cluster is split further. At inference, the agent conditions on both concrete trajectories and their distilled skills, so it gets execution templates without inheriting cross-environment interference.

The paper evaluates this on 10 environments and more than 13k tasks, adding 2k+ newly annotated interaction trajectories where existing benchmarks had no training split. On average overall performance, LifeMem reaches 44.13 on GPT-4o-mini, 48.02 on Deepseek-v3.2-exp, and 46.52 on Qwen3-32b, versus the best baselines at 41.85, 46.38, and 43.29. For zero-shot transfer, it scores 0.49 on FEVER for GPT-4o-mini against ReAct's 0.40, and 0.38 on $\tau$-bench airline against 0.32.

The interesting part is not just the absolute gain; it is that positive transfer survives as the memory grows and the task stream changes. Random streams drop GPT-4o-mini to 39.63, while similarity-based streaming restores 44.13, which supports the paper's claim that structure in the stream matters. The caveat is that the strongest evidence is still benchmark-scale, and the authors only sketch how to scale to million-entry memories with lighter local models and approximate retrieval.

方法Method

core idea

Each cluster is then distilled into an environment-invariant textual skill, and inference activates both the concrete trajectories and the skill.

Current multimodal time series forecasting methods often fuse temporal patches and text tokens in a shared embedding space. That token-level fusion is brittle when high-quality time-text pairs are scarce and when the series themselves vary a lot across regimes, because cross-modal alignment becomes the bottleneck.

The key move is Expert Modulation: textual signals condition both the router and the experts, so language does not need to align with every temporal token. Instead, it directly steers which expert is activated and how that expert computes, turning multimodal interaction from token mixing into expert control.

The abstract says the authors provide theoretical analysis and experiments, and that the method shows strong improvements on multimodal time series prediction. But it gives no benchmark names, metrics, or numbers, so the magnitude of the gain is not visible from the text alone. The code is available on GitHub.

For readers doing time series forecasting with covariates or text side information, the mechanism is well matched to the failure mode of token fusion. The catch is that, from the abstract alone, we cannot tell how much of the win comes from the modulation scheme itself versus data or backbone choice, or how it behaves when paired data are truly sparse.

DCRA turns the forward diffusion process into a structured corruption scheduler for representation learning. The core move is a feature-level consistency loss that aligns representations across noise levels while preserving class-discriminative structure, so the latent trajectory stays smooth and semantically coherent.

On CHB-MIT EEG seizure detection, the paper reports consistent gains across multiple noise conditions and higher sensitivity at low false-positive rates. It also argues that DCRA yields more balanced and structured representations than both baseline and diffusion-only models.

The useful idea is to make corruption ordered rather than random, then align features along that path. But the evidence in the abstract is narrow: only CHB-MIT EEG is mentioned, and there is no visible cross-dataset or ECG result to tell us how general the effect is.

现有 time series explanation 多半只给一条重要性向量，默认所有预测步都依赖同一批历史点。但不同 horizon 往往看的是不同过去，这个假设一旦错了，解释就会把步间差异抹平。

HRX 的关键动作是给解释加一条 horizon 轴：每个 forecast step 都有自己的 importance map。它还是一个 plug-in 框架：用一个估计器从任意可微 forecaster 里读出这些 map，不改 TS backbone；再用一个按单步删除高排名输入来检验该轴是否真的有用的评估协议；最后用一个 rank criterion 预先判断某个 TS 值不值得细分 horizon。

摘要只说了实验覆盖多种 backbones 和 datasets，并且收益来自 horizon 轴，本身也适用于以往解释方法的 estimators，但没有给出具体数值。作者还报告，这种 step-wise dependence 是 low-dimensional 的：所有步的解释可由少数共享 maps 构成，其数量不随 forecast length 增长。

这项工作对解释长预测窗的 time-series 模型很直接：它不是再做一条全局热力图，而是把“哪个历史点重要”改成“对哪一步重要”。但摘要层面还看不出它在多长的 horizon、哪些数据集上最稳，也看不出和简单分步基线相比的量化收益。

Most time-series explanation methods return one importance vector and implicitly assume every forecast step depends on the same past inputs. That is a weak assumption: different horizons can rely on different historical points, so a single map can flatten step-specific structure.

HRX adds a horizon axis to attribution. The framework is plug-and-play: an estimator reads per-horizon maps from any differentiable forecaster without changing the TS backbone, an evaluation protocol tests the axis by removing the inputs that each map ranks highest and measuring the effect on a single forecast step, and a rank criterion decides ahead of time whether a given series is worth resolving by horizon.

The abstract claims the method was tested across multiple backbones and datasets, and that the gain comes from the horizon axis itself. It also says the same horizon-resolved benefit appears when HRX is paired with estimators from earlier explanation methods. No headline numbers are given in the abstract, so the quantitative scale of the improvement is unclear.

The substantive takeaway is that step-wise dependence can be low-dimensional: all horizons can be represented by a few shared maps, and the number of these maps does not grow with forecast length. That makes HRX relevant for interpreting long-horizon forecasters, but the abstract-only view leaves open how robust the claim is across datasets, horizons, and backbone choices.
