Shared Selective Persistent Memory for Agentic LLM Systems

只存 4 类上下文，在 24 任务上完成 23/24，并可零 token 刷新。

Keeping four reusable context types lifts completion to 23/24 and enables zero-token refresh; raw transcripts are costlier and worse.

智能体每跑完一次任务就把上下文清空。下次再做同类 dashboard、report 或 artifact，schema、工具配置、输出格式和领域约束都得重说一遍。把整段 transcript 塞回去确实能补信息，但它把一次性的推理轨迹也一起带上，token 变多，结果未必更稳。

关键动作是把可复用内容拆成四类：$\mathcal{M}_{\text{task}}$、$\mathcal{M}_{\text{data}}$、$\mathcal{M}_{\text{tools}}$、$\mathcal{M}_{\text{output}}$，只存配置，不存 reasoning trace、tool log、临时文件和失败路径。新会话用 $s'=s_{\text{base}}\oplus\mathcal{M}_{\text{task}}\oplus\mathcal{M}_{\text{tools}}\oplus\mathcal{M}_{\text{output}}$，数据用 $q'=q\oplus\mathcal{M}_{\text{data}}$ 注入；再用 data-injection contract 约束程序只从运行时取数，所以 schema-compatible 更新可以零 token 刷新。

在 24 个企业任务上，selective memory 完成 $23/24$，no memory 是 $19/24$，full history 是 $17/24$；full history 的输入 token 达 18.7K，是 no memory 的 $9\times$。公开数据复现里，selective 是 $12/12$，full history $8/12$，no memory $0/12$，而 selective 的输入只有 3.9K token，和 no memory 的 3.8K 几乎一样。零 token 刷新在 $12/12$ 次 schema-compatible 更新上触发，median 0.08s；$N=12$ 的用户研究也把 recurring generation 拉到 12s，对照 165s。

这说明瓶颈更多是 context management，而不是模型本身的 reasoning。它对结构化表格和稳定 schema 很合适；但一旦有跨源 join，$\mathcal{M}_{\text{data}}$ 不记录 source 之间的关系，就会漏掉约束。证据也还偏窄：单一 model family、每格单跑，且缺少 summarized-history、手写 instructions 和 leave-one-component-out baseline；公开集上 $12/12$ 对 $8/12$ 的差异在 $N=12$ 下也没到显著。

The failure mode is simple: every agent session starts blank, so the next dashboard, report, or code artifact has to be re-specified from scratch. Schema assumptions, tool configs, output formats, and domain rules all get re-entered. Feeding back the whole transcript does recover some context, but it also carries over session-specific reasoning paths, which costs tokens and does not reliably buy better outcomes.

The paper's move is to persist only the reusable pieces. It splits memory into four buckets: task specs, data schemas, tool configs, and output constraints, while discarding reasoning traces, tool logs, temp files, and failed recovery paths. New sessions compose the prompt as $s'=s_{\text{base}}\oplus\mathcal{M}_{\text{task}}\oplus\mathcal{M}_{\text{tools}}\oplus\mathcal{M}_{\text{output}}$, with $q'=q\oplus\mathcal{M}_{\text{data}}$ for the data profile. A data-injection contract forces generated programs to read only from runtime data, which makes schema-compatible refreshes zero-token.

On 24 enterprise tasks, selective memory completed 23/24, versus 19/24 for no memory and 17/24 for full history. Full history used 18.7K input tokens, about 9x no memory, yet finished fewer tasks. In the public replication on four datasets, selective memory reached 12/12, full history 8/12, and no memory 0/12, while selective used 3.9K input tokens, essentially the same as no memory at 3.8K. Zero-token refresh fired on 12/12 compatible updates with a median latency of 0.08s. A $N=12$ user study pointed the same way: recurring generation took 12s versus 165s.

The practical point is that context management, not raw reasoning, is often the bottleneck. But the design is best suited to structured tabular workflows with stable schemas and versioned artifacts. It breaks on cross-source joins because the data schema memory stores each source independently and does not encode relationships across sources. The evidence is still narrow: one model family, single runs per cell, no summarized-history or hand-written-instructions baseline, and a $N=12$ user study that is too small for strong item-level inference.

语言模型 agent 在 tool use 里会被间接 prompt injection 钻空子：不可信工具输出里的隐藏指令，能悄悄改写后续执行。现有防御多半只对固定攻击训练和评测，攻击者不随防御变化，因而高估了鲁棒性。

关键动作是把 adaptive IPI 写成 general-sum Markov game，再做 verifier-grounded 的 CoER。攻击者和防御者先共同演化：Co-PPO 保留双方历史策略作为 opponent populations，把当前与历史对手混合进双边强化学习，逼防御者不只适应“最新一招”。

随后把这些攻击者拿去挑战 teacher agents，只保留同时通过安全性和任务完成验证的示范，再用它们 fine-tune 防御者。摘要给出的主实验是在 7 个领域上，overall attack success 从 $38.5\%$ 降到 $0.2\%$，task utility 从 $63.2\%$ 升到 $76.3\%$，外部 benchmark 上也更抗攻击。

这篇工作的价值在于，它承认防御面对的是会学习的对手，而不是静态脚本。短板也清楚：现在只看到摘要，验证器是否覆盖真实部署中的所有失败模式、以及共演化是否会把攻击面局限在训练族群里，还看不到。

Language-model agents fail open to indirect prompt injection during tool use: hidden instructions in untrusted tool outputs can quietly steer later actions. Most prior defenses are trained and evaluated against fixed attacks, so they look stronger than they are once the attacker adapts.

The move here is to cast adaptive IPI as a general-sum Markov game and train both sides in a verifier-grounded co-evolution loop. Co-PPO keeps historical policies from each role as opponent populations, then mixes current and past opponents in bilateral reinforcement learning so the defender is not only fitted to the latest attack pattern.

Those evolved attackers are then reused to pressure teacher agents, and only demonstrations that pass both safety and task-completion checks are used to fine-tune the defender. In the main seven-domain evaluation, overall attack success falls from 38.5% to 0.2%, while task utility rises from 63.2% to 76.3%; the abstract also says resistance improves on external benchmarks.

The paper’s core claim is well-targeted: if the threat model is adaptive, the defense pipeline has to be adaptive too. What is still unclear from the abstract is how broad the verifier coverage is in deployment, and whether the co-evolution setup overfits to the attack families seen during training.

The real bottleneck in long-horizon agents is not storage, but that memory is usually updated only when new information arrives. Retrieval ends the interaction instead of changing how memory will be accessed next time, and fixed memory layouts leave little room for autonomous evolution.

REALM turns long-term memory into a continual lifecycle. It organizes memories into a heterogeneous cognitive graph, retrieves evidence with adaptively composed graph-search atoms, and then reconsolidates memory using retrieval feedback. The key move is to make retrieval a signal that reshapes memory structure, not just a readout step.

The abstract reports $75.97\%$ average accuracy on LoCoMo and $65.11\%$ on LongMemEval, beating the strongest baselines by $7.17$ and $1.31$ points. Ablations show that reconsolidation consistently improves performance, and the analysis suggests it progressively clusters related memory units into more coherent local structures for joint recall and reasoning.

The paper's strongest contribution is conceptual: it reframes agent memory as something that should reorganize itself after being used. That is a good fit for long-term agent memory work. But with only the abstract, the mechanics remain underspecified: how graph-search atoms are composed, how the graph is formed, and whether the gains survive harder environments are all open.

Blindspot 的关键动作是把整条 trajectory 当评测对象。User Agent 按已见到的回复自适应出题，Target Agent 在有状态的工具环境里行动，最后用执行痕迹、授权状态、policy 条件和语义判定，把轨迹分成 Safe Completion、Correct Refusal、Unsafe Completion、Over-Refusal、Indeterminate。

作者构造了 22 个 attack families、35 个 scenarios、7 个 domains 的 live-simulation，并评测 13 个 proprietary 和 open-weight 模型。GPT-5.6 Sol 的 UCR 低到 2%，SCS 为 96.0；Llama-3.3-70B 的 BCR 到 97%；Mistral Large 3 的 UCR/ORR 升到 58%/33%。

Current agent-safety evaluation still collapses long-horizon tool use into a single jailbreak-style success rate. That misses the distinction between correct refusal, over-refusal, and failures that only appear after authorization or environment state changes. In long tasks, the dangerous part is often the part that comes late, after several apparently safe steps.

Blindspot’s move is to score the whole trajectory. A User Agent adapts each new request to the Target Agent’s observed behavior, while the Target Agent acts inside a stateful tool environment. The benchmark grounds judgment in execution traces, authorization state, policy conditions, and semantic review, then assigns one of five outcomes: Safe Completion, Correct Refusal, Unsafe Completion, Over-Refusal, or Indeterminate.

The current instantiation spans 22 attack families, 35 scenarios, and 7 domains, and yields more than 2,500 trajectories with an average length of 14.7 turns. The authors evaluate 13 proprietary and open-weight models. GPT-5.6 Sol gets the lowest UCR at 2% and an SCS of 96.0; Llama-3.3-70B reaches the highest BCR at 97%; Mistral Large 3 climbs to 58% UCR and 33% ORR.

Fail@k also rises with repeated runs. The paper’s limitation is breadth, not direction: the benchmark is still a 22-by-35 initial map, and adjudication still depends on judge and human review.

现有 agentic society 的问题不是“能不能通信”，而是跨 trust boundary 的协作会被脆弱的 messaging primitive 放大成失效：即便 honest、competent 的 agent 也常拿不到满意结果，faulty 或 malicious 的 agent 还可能借“speech”卡住协作、影响结果、追求别的坏目标。

关键动作是把单个 agent 的 personal harness 之外，再加一层 social harness，专门管 agent 之间的交互。作者给出的层级架构分三类能力：直接阻断某些失败；让 agent 在运行时识别 invalid message；以及在事后支持调查和追责。

The failure mode is not that agents cannot talk; it is that cross-boundary coordination can break even when agents are honest and competent. Existing harnesses and messaging primitives leave room for stalled collaboration, outcome manipulation, and other harmful behavior by faulty or malicious agents exploiting weaknesses in “speech.”

The move is to add a social harness on top of each agent’s personal harness. The proposed layered design aims to block some failures outright, help agents detect invalid messages at runtime, and preserve evidence for post-facto investigation and consequences.

The abstract says they show these failures experimentally, but it gives no benchmark, task count, or quantitative gains. So the evidence here is mainly diagnostic: the paper argues that the problem is real and structural, not just a prompt-engineering glitch.

For the agent reader, the relevance is direct: this is about multi-agent coordination, communication protocol design, memory/context separation, and adversarial robustness in agent societies. Confidence is limited because only the abstract is available.

SOTER 的关键动作是把三件事绑进同一套 pre-training：空间特征骨干建模跨信号依赖，PSD-guided mixture-of-experts 用固定频带的可解释规则把表示路由给不同 expert，最后用 neural controlled differential equation decoder 支持任意时间戳的预测和 imputation。

作者在 5 个公开生理数据集上预训练了 $226$0 亿个时间点，并在 OOD zero-shot forecasting、frozen-encoder linear-probe classification 和连续时间 imputation 上评估同一个预训练模型。摘要给出的结果是：zero-shot forecasting 在 $6$ 个数据集里 $4$ 个拿到最优 RMSE、$5$ 个拿到最优 MAE；classification 里平均 Macro-AUROC 最高；在 $75\%$ 缺失率下，6 个数据集的 imputation error 全部最低。

Standard time-series foundation models fit wearable physiology poorly: these signals are multichannel, irregularly sampled, noisy, and driven by coupled continuous-time dynamics across spectral scales. A generic backbone alone is a bad match for that mix of structure and sampling.

The move here is to train one model around three coupled components: a spatial feature-aware backbone for inter-signal dependencies, a PSD-guided mixture-of-experts layer that sends representations to fixed spectral-band experts through a non-learned, inspectable rule, and a neural controlled differential equation decoder for prediction and imputation at arbitrary timestamps.

The model is pretrained on 226 billion time points from five public physiological datasets. On the reported benchmarks, it gets the best RMSE on 4 of 6 datasets and the best MAE on 5 of 6 for zero-shot forecasting, the highest average Macro-AUROC for frozen-encoder classification, and the lowest imputation error on all six datasets at 75% missingness. It also stays robust under additive acquisition noise, matching or beating baselines even under the strongest corruption.

The paper’s main claim is plausible: for wearable physiology, inductive bias about channel structure, spectral scale, and continuous-time dynamics seems to matter more than a larger generic foundation model. But this is abstract-only evidence, so the exact baselines, ablations, and noise protocol are not visible. I would treat the performance claims as promising but not yet fully audit-able.
